# 股票短線交易訓練工具 (MWE)

用 `yfinance` 取得歷史股價，以「下一天」按鈕逐日推進、顯示當天收盤價，
模擬「只看得到今天收盤、就要判斷下一步」的短線交易訓練情境。

## 安裝

需要 Python 3.10+（Windows 可至 [python.org](https://www.python.org/downloads/) 下載，
安裝時勾選 **Add python.exe to PATH**）：

```bash
pip install -r requirements.txt
```

## 執行

```bash
streamlit run app.py
```

瀏覽器會自動開啟 `http://localhost:8501`。

## 使用方式

1. 左側欄選擇市場（美股／港股／A股）並輸入代號（預設美股 AAPL，開始日期預設近 3 個月——原地追加模式下區間越短、蠟燭越大；注意 MA120／MA250 需要夠長的歷史區間才會出現）：
   - 港股輸入數字自動補全為 `0700.HK` 格式（如 700 → 0700.HK）
   - A股輸入 6 位數字依開頭自動補上交易所：6 開頭 → `.SS`（滬）、0/3 開頭 → `.SZ`（深）
2. 貨幣單位隨市場自動切換：美股 USD $／港股 HKD $（3 位小數）／A股 CNY ¥；漲跌配色可選「紅漲綠跌（台/港/A股慣例，預設）」或「綠漲紅跌（美股慣例）」（空心漲／實心跌的形狀通道兩種模式皆保留），並連動買入=漲色／賣出=跌色按鈕與升跌徽章正負色；圖表背景自動同步應用深淺主題。
3. 頁面顯示區間內第一天的日期、收盤價與當天 OHLCV，以及**只畫到當前模擬日期**的動態 K 線圖（疊加 MA5／10／20／60／120／250 六條均線、線尾標註，含跟隨漲跌色的當前股價虛線與價籤，支援滑鼠滾輪縮放，週末與休市日不佔圖表空間，**X／Y 軸皆固定於完整資料區間——點擊推進時既有 K 線的位置與大小完全不變，新蠟燭在原地出現**，未來數據完全隱藏）。
4. **畫線工具**（模式列按鈕）：直線／矩形／自由繪，可畫支撐壓力線、趨勢線、價格區間——畫完即保存（跨 rerun 與重新整理保留），推進模擬後線條留在原價位，可拖曳頂點微調；**橡皮擦**：點一下按鈕（高亮）進入擦拭模式 → 點擊線條即刪除（現價線除外）→ 再點橡皮擦或點其他工具退出；換標的或日期區間會自動清空。預設工具為平移（框選縮放工具已移除；縮放可用滾輪或放大／縮小按鈕）。
5. 模擬交易：初始資金 10,000（以所選市場貨幣計）。輸入股數後按「買入 🟢／賣出 🔴」以當天收盤價成交；買入以綠色▲標註於 K 線下方、賣出以紅色▼標註於上方。
6. 資產看板即時顯示持倉數量、平均成本（移動平均成本法）、剩餘現金、總資產、總收益與累積收益率（後兩者附前後變化 delta，正=紅、負=綠）。
7. 點「下一天 ➡️／下一週 ⏩（+5天）／下一月 ⏭️（+20天）」推進模擬（剩餘天數不足會推進至最後一天）；「重設 🔄」重啟整個模擬（回到第一天並清空帳戶）。
8. 推進到結束日期時**自動結算**：顯示最終收益率、總交易次數與勝率，並停用交易功能。
9. 更換市場、代號或日期會自動重設模擬（歷史數據以快取保存，相同區間不會重複下載）。
